# BloomPod Professional Website v4

This revision uses **six separately generated product renders**. None of the website images were cropped out of the earlier website mockup.

## Included image assets

- `hero-open.png`
- `hero-closed.png`
- `opening-view.png`
- `open-studio.png`
- `open-front.png`
- `closed-studio.png`

## Run locally

Open `index.html`, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish

Upload the complete folder to GitHub Pages, Netlify or another static hosting service. Keep the `assets` folder beside the HTML, CSS and JavaScript files.
